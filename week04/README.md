자료: 교안 03 / 수업 4주차. 폴더는 수업 주차 기준이다.

## 학습 목표와 핵심 개념
grep은 텍스트를 검색하고 find는 파일을 검색한다. 파이프는 앞 명령의 출력을 다음 명령의 입력으로 연결한다. 프로그램은 저장된 코드이고 프로세스는 실행 중인 인스턴스다. tar로 백업하고 diff로 복원본을 검증한다.

## 실행 방법
```bash
bash ./backup.sh test; grep -c ERROR ./test/server.log
```

## 교안 04: 네트워크

자료: 교안 04 / 수업 4주차. 폴더는 수업 주차 기준이다.

## 학습 목표와 핵심 개념
IP는 네트워크 주소이고 포트는 서비스를 구분한다. DNS는 이름을 IP로 해석한다. localhost는 자신이다. 0.0.0.0 바인딩과 127.0.0.1 바인딩은 접근 범위가 다르다. Docker의 호스트 포트와 컨테이너 포트도 구분해야 한다.

## 실행 방법
```bash
ip addr; ss -ltn; curl -I http://127.0.0.1:8080
```
